# 🕘 Attendance & OT Notification System

## 📌 Project Overview

Attendance & OT Notification System is a Python-based automation application designed to simplify employee attendance and overtime reporting.

The system processes attendance data and identifies late punch-in, early punch-out, missing punch-out and overtime conditions.

## 🎯 Business Problem

HR teams often spend significant time checking attendance data manually.

Common problems include:

- Late punch detection
- Missing punch-out
- Early punch-out
- Overtime calculation
- Monthly overtime reporting
- Manual HR reporting

## 💡 Solution

I developed an automated attendance processing system that reads attendance data and generates attendance and overtime information automatically.

## 🚀 Key Features

## 📊 Attendance Conditions

### Normal

Employee punches within the expected shift timing.

### Late Punch

Punch-in occurs after the defined shift start time.

### Early Out

Punch-out occurs before the defined shift end time.

### Missing Punch

Required punch information is missing.

### Overtime

Punch-out occurs after the normal shift end time.

## 📈 Business Value

The system helps HR teams reduce manual attendance checking and generate attendance and overtime reports more efficiently.
